This module implements the infrastructure layer of a DDD-style architecture. It depends on `:j-store-fulfillment-domain` (via `api`) to implement the `FulfillmentOrderRepository` interface defined in the domain project, while depending on `:j-store-common-core` for shared utilities. The package structure mirrors the domain: `persistence/` holds JPA entities (`FulfillmentOrderPO`, `FulfillmentItemPO`) and the Spring Data repository interface (`FulfillmentOrderPOJpaRepository`), while `FulfillmentOrderRepositoryImpl` at the root provides the concrete repository implementation with `toPO`/`toDomain` conversion functions that bridge domain entities and persistent objects. Spring's `@Repository` and `@Transactional(propagation = MANDATORY)` are used to wire persistence transactions. The build uses Kotlin JVM with Spring Boot JPA starter and an embedded Postgres for tests via `io.zonky.test:embedded-postgres`.
