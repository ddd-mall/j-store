This module is the JPA infrastructure slice of the accounting subsystem. Each domain aggregate (account, journal, settlement) has a consistent three-file layout under `src/main/kotlin/com/jstore/accounting/domain/<aggregate>/`: a `persistence/` subpackage holding the `*PO` JPA entities and their `*JpaRepository` Spring Data interfaces, plus an `*RepositoryImpl` class that implements the domain's repository interface. The `*RepositoryImpl` classes are Spring `@Repository` beans that delegate to the JPA repositories and perform bidirectional mapping between domain objects and POs via an inner `object Converter` with `toPO`/`toDomain` methods. Persistence is transactional through `@Transactional(propagation = Propagation.MANDATORY)` on mutating methods, enforcing that callers must already be inside a transaction. Tests use an in-memory H2 database configured via `AccountingJpaTestConfig` with `@EntityScan` and `@EnableJpaRepositories` scoped to `com.jstore.accounting`. Dependency direction is strictly inward: this module depends on `j-store-accounting-domain` (API) and `j-store-common-core`, never the reverse.
