Single Spring Boot executable (JStoreOrderBootApplication.kt) that wires together multiple sibling Gradle projects: j-store-order-domain/boot, j-store-payment-domain/boot, j-store-fulfillment-domain/boot, j-store-goods-domain/boot, j-store-user-domain/boot, j-store-shop, j-store-shop-infrastructure, j-store-common-core/spring, j-store-integration-contracts, j-store-authentication-spring-sdk, and j-store-accounting-boot. The app enables JPA auditing, scheduling, and configuration properties binding, then exposes controllers under com.jstore.{outbox,shop,translator} for operational endpoints and cross-domain event translation. Persistence is PostgreSQL via Spring Data JPA with Flyway migrations under resources/db/migration; Redis is used for distributed coordination. A custom timer job subsystem (com.jstore.order.expired.*) implements a database-backed job queue with retry, dead-letter, and timeout monitoring using Lua scripts (PickOneOutAndPrepare.lua, RollbackExpired.lua, RollbackTimerJob.lua). j-store-admin-boot is a separate minimal Kotlin JVM project with no Spring dependencies, serving as an admin utility shell.
