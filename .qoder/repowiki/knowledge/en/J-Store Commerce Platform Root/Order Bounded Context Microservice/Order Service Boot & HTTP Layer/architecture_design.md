This module is the Spring Boot bootstrapping layer for the order service. It depends on `j-store-order-domain`, `j-store-order-application`, and `j-store-order-infrastructure` (plus shared modules like `j-store-common-*`, `j-store-goods-api`, `j-store-authentication-spring-sdk`) and provides three concerns:
- Controllers (`OrderController`, `AfterSaleController`) expose `/api/orders` and `/api/after-sales` REST endpoints, translating request DTOs into domain commands and mapping domain results to JSON responses via a shared `Result.fold` pattern.
- Configuration (`OrderBootConfiguration`) assembles beans: factories (`OrderFactory`, `AfterSaleFactory`), application services (`OrderService`, `AfterSaleApplicationService`), transactional use-case wrappers (`TransactionalOrderUseCase`, `TransactionalAfterSaleUseCase` marked `@Primary`), event handlers for payment/fulfillment/stock events, and the Spring-backed domain event bus (`SpringDomainEventListenerRegistry`, `LocalDomainEventBus`, `SpringDomainEventListenerRegistrationMachine`).
- Infrastructure wiring (`RedisConfig`) sets up `RedisTemplate` with String keys and JSON values.
Dependency direction is one-way: this layer depends on application/domain interfaces but never on persistence implementations; transaction boundaries are explicitly drawn via `PlatformTransactionManager`/`TransactionTemplate` rather than `@Transactional` annotations.
