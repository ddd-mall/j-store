This module implements the `PaymentOrderRepository` interface from the payment domain via a single `PaymentOrderRepositoryImpl` class annotated with `@Repository`. It depends on the domain project (`:j-store-payment-domain`) as an `api` dependency and uses Spring Data JPA to persist three JPA entities defined in `persistence/`: `PaymentOrderPO` (mapped to `payment_orders`), `PaymentRefundPO` (mapped to `payment_refunds`), and `PaymentRefundItemPO` (mapped to `payment_refund_items`). The POs form a one-to-many hierarchy with eager fetching and cascading all operations. Domain↔PO conversion is handled by private `toPO` and `toDomain` methods inside the repository impl, keeping the adapter thin. Transaction boundaries are enforced with `@Transactional(propagation = Propagation.MANDATORY)` on write operations, requiring an outer transaction.
