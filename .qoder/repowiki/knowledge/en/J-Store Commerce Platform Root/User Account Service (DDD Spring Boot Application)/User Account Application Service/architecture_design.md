Kotlin/JVM module implementing the application layer of a DDD-based user service. It exposes `UserAccountUseCase` interface implemented by `UserAccountService`, which orchestrates domain aggregates (`UserAccount`) loaded from `UserAccountRepository` through factories and repositories from `:j-store-user-domain`. Cross-cutting concerns (password hashing, token issuance/storage, phone verification, login attempt guarding, domain event publishing) are injected as collaborators rather than implemented here. A separate read-only `UserProfileReader` adapts domain entities to DTOs in `:j-store-user-api`. `RefreshTokenDigest` provides SHA-256 hashing used with `TokenStore.rotateRefreshSession` for secure refresh-token rotation. The module depends only on domain, API, and common-core modules — no inbound dependencies from infrastructure or presentation layers.
