Pure Kotlin domain module following DDD aggregate-root pattern. The core is the `UserAccount` interface (`UserAccount.kt`) extending `AggregateRoot<UserId>` and `RecordsDomainEvents`, with `UserAccountImpl` as its concrete implementation built on `EventRecordingAggregateRoot`. Creation is delegated to `UserAccountFactory` / `UserAccountFactoryImpl`, which validates inputs, hashes passwords through injected `PasswordHasher`, generates IDs via `SnowFlakSequence`, and raises `UserAccountRegisteredEvent`. Persistence is abstracted by the `UserAccountRepository` interface extending `AggregateRepository<UserId, UserAccount>`, kept in the domain so implementations live in the infrastructure layer. Value objects (`Nickname`, `Password`, `UserId`, `AuthTokenPair`) enforce invariants in their constructors. Domain events under `event/` are annotated with `@DomainEventType`. Commands under `command/` carry inbound data into the factory. Tests use Kotest property-based testing to verify invariants across generated inputs.
