The module is a pure infrastructure implementation of the `j-store-goods-domain` repository contracts. It follows a classic DDD hexagonal pattern: each domain aggregate (Spu, GoodsStyle, SpuSnapshot) has a `*RepositoryImpl` class annotated with `@Repository` that implements the corresponding domain interface, a `persistence/` sub-package containing JPA `@Entity` PO classes (`SpuPO`, `SkuPO`, `GoodsStylePO`, `SpuSnapshotPO`) plus Spring Data `JpaRepository` interfaces, and an internal `Converter` object per repository handling bidirectional conversion between domain and PO types. Dependency direction is strictly inward toward `j-store-goods-domain` (declared as `api(project(":j-store-goods-domain"))`); the module depends on Spring Data JPA, PostgreSQL runtime, and shared utilities like `JsonUtils` and `Price`. Transaction boundaries are enforced via `@Transactional(propagation = Propagation.MANDATORY)` on mutating operations, ensuring they run within an existing transaction.
