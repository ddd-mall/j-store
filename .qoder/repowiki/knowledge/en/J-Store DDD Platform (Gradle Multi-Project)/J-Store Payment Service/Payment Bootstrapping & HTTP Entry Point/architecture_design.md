This module is the Spring Boot bootstrapping layer of the payment subsystem. It contains only three Kotlin files: `PaymentBootConfiguration` registers beans for `PaymentApplicationService`, a `@Primary` `TransactionalPaymentUseCase` decorator (wrapping the core `PaymentUseCase` with explicit read/write `TransactionTemplate`s), and two command handlers (`CreatePaymentForOrderCommandHandler`, `RequestPaymentRefundCommandHandler`). `PaymentController` is the single REST boundary under `/api/payments`, delegating to `PaymentUseCase` after merchant-permission checks via `MerchantAuthorizationService`. The controller uses `@RequireLogin` and `@CurrentUserId` annotations from `j-store-authentication-spring-sdk` for auth. Dependency direction is strictly inward: this module depends on `:j-store-payment-domain`, `:j-store-payment-application`, `:j-store-payment-infrastructure`, plus shared modules (`j-store-common-core`, `j-store-common-spring`, `j-store-integration-contracts`, `j-store-shop`, `j-store-authentication-spring-sdk`) but exposes no APIs to them — it is a leaf adapter layer.
