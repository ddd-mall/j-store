Pure DDD domain layer built around a single aggregate root `PaymentOrder` (interface) implemented by `PaymentOrderImpl`. The aggregate extends `EventRecordingAggregateRoot<PaymentOrderId>` from `j-store-common-core`, which provides event recording via `raise()`/`pendingDomainEvents()`/`acknowledgeDomainEvents()`. State transitions are modeled as methods (`capture`, `requestRefund`, `retryRefund`, `markRefundSucceeded`, `markRefundFailed`) that mutate internal state and publish typed domain events. Events live in a separate `event` sub-package as data classes extending a sealed `PaymentDomainEvent` base, each annotated with `@DomainEventType(name = ...)`. Persistence is abstracted through the `PaymentOrderRepository` interface extending `AggregateRepository<PaymentOrderId, PaymentOrder>`, keeping the domain decoupled from storage. Business invariants are enforced via `require` blocks in constructors/init and explicit `BusinessError` failures returned through the `Result<Boolean, BusinessError>` return type. Tests use Kotest FunSpec to exercise state machines and verify emitted events.
