Pure Kotlin JVM module implementing a DDD bounded context with two aggregate roots under `src/main/kotlin/com/jstore/order/domain/`: `order` (Order + OrderItem) and `aftersale` (AfterSale). Each aggregate follows an interface-implementation split — e.g. `Order` / `OrderImpl`, `AfterSale` / `AfterSaleImpl` — extending `AggregateRoot<T>` and `RecordsDomainEvents` from `com.jstore.common.framework`, so state mutations are expressed as domain events via `raise(...)`. State transitions go through a private `transition(valid, operation, action)` helper that validates preconditions, mutates state, calls `touch()` to update timestamps, and returns `Result<Unit, BusinessError>`. Cross-boundary dependencies are isolated in `acl/` (`GoodsService`, `GoodsId`, `GoodsInfo`) and injected only into factories (`OrderFactoryImpl`), never into aggregates. Persistence is abstracted by repository interfaces (`OrderRepository`, `AfterSaleRepository`) extending a common `AggregateRepository<I, E>`. Command DTOs live in `command/` subpackages; domain events live in `event/` subpackages. Test code uses Kotest FunSpec with property-based tests (kotest-property) and a shared `testFixtures` source set exposing `testOrder(...)` helpers.
