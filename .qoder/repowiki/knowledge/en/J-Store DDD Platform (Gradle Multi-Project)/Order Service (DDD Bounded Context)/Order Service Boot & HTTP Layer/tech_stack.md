Kotlin JVM with Spring Boot (spring-boot-starter-web, spring-boot-starter-data-redis, spring-boot-starter-validation). Uses embedded Postgres via `io.zonky.test:embedded-postgres` for tests, Mockito + mockito-kotlin for mocking, JUnit Platform, and JDK 25 toolchain. Domain events are handled through a custom `SpringDomainEventListenerRegistry` backed by Spring's `ApplicationEventPublisher`.
