Single-package application layer under `com.jstore.user.service` exposing one interface (`UserAccountUseCase`) implemented by `UserAccountService`. The service is a thin orchestrator: it loads aggregates via `UserAccountRepository`, delegates state mutations to domain objects on `UserAccount`, persists through the repository, and publishes side effects via `DomainEventPublisher` (using `publishPendingEvents` on aggregates plus explicit `publishEvent` calls). Cross-cutting concerns are injected as constructor dependencies — `UserAccountFactory`, `PasswordHasher`, `TokenProvider`, `TokenStore` — keeping the service free of infrastructure. Tests mirror this structure with all collaborators mocked via Mockito-Kotlin and Kotest `FunSpec`. Dependency direction is strictly inward toward `:j-store-user-domain` and outward only through the `UserAccountUseCase` interface; no inbound dependencies from higher layers are present in this module.
