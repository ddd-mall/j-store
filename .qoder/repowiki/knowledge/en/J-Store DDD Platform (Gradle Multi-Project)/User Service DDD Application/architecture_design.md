The module follows a strict unidirectional dependency split across four Gradle subprojects: `j-store-user-domain` declares pure Kotlin contracts (aggregate, value objects, repository/event interfaces); `j-store-user-infrastructure` implements those contracts via Spring Data JPA (PostgreSQL), Redis, BCrypt, and HS256 JWT; `j-store-user-application` composes domain + infrastructure into use-case operations returning `Result<UserAccount, BusinessError>`; `j-store-user-boot` is the Spring Boot entry that wires all layers through `UserBootConfiguration`, exposes REST endpoints under `/api/users`, and registers `JwtAuthenticationFilter`. Cross-layer wiring is centralized in `TransactionalUserAccountUseCase` which wraps `UserAccountService` with transactional boundaries. Domain events are published through the shared `DomainEventPublisher` from `com.jstore.common.framework.event`, and all layers reuse common types (`SnowFlakSequence`, `BusinessError`, `PhoneNumber`, `Result`) from `com.jstore.common.utils`.
