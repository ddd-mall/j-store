The root is a Gradle multi-project (`settings.gradle.kts`) that declares every submodule via `include(...)`, establishing a strict dependency hierarchy: foundational libraries `j-store-common-core` and `j-store-common-spring` are consumed by all services; each bounded context (order, goods, user, shop, accounting, payment, fulfillment) follows the same four-layer split (domain/application/infrastructure/boot); `j-store-order-boot` acts as the primary orchestration application wiring all contexts together. Cross-cutting concerns are centralized in `j-store-authentication-spring-sdk`, `j-store-common-core`, and `j-store-common-spring`. Database schema and migrations live in `docker-compose.postgres.yml` plus SQL migration scripts, while `tests/` enforces module boundary contracts via Python unittests. The root `build.gradle.kts` centralizes Java 25 toolchain, Spotless formatting, and CycloneDX BOM generation for all subprojects.
