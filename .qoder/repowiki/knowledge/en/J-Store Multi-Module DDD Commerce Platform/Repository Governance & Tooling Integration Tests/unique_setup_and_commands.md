Tests must be run from within this workspace because they resolve paths relative to `__file__` (two or three parent directories up). The spec-dev tests require the `.codex/skills/spec-dev` directory tree (schemas, evals/cases, evals/runs) to exist on disk, and the governance tests require `scripts/check-agent-governance.sh` and `.codex/agents/*.toml` files. The spotless hook test skips itself if no POSIX shell is available (`shutil.which("sh")`).
