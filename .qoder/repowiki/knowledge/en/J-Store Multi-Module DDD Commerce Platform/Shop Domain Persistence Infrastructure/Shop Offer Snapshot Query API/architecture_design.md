A minimal Kotlin/JVM library module that publishes a single public boundary: the `OfferSnapshotQueryService` functional interface with a `queryOffers` method returning a list of `OfferSnapshotInfo` data objects. The module depends only on `j-store-common-core` (for shared types like `Price`) and exposes its surface via `api(...)` dependencies so consumers can reference the types directly. There is no runtime framework or server code — it serves purely as an API contract module between the shop layer and downstream implementations.
