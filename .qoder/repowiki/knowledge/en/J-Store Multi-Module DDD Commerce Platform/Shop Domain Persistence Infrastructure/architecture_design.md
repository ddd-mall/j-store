Single Gradle subproject that depends on `:j-store-shop-domain` (via `api(project(...))`) and `:j-store-common-core`, keeping persistence as a leaf layer with no upward dependency. Code is organized per aggregate under `com.jstore.shop.domain.<aggregate>` (`merchant/`, `offer/`), each exposing a `persistence/` sub-package containing `@Entity` POs and Spring Data `*JpaRepository` interfaces, plus sibling `*RepositoryImpl` classes that implement domain repository ports and delegate to those Spring Data repos. The module is consumed by higher-level shop services; it does not own application wiring beyond declaring `@Repository` beans. A single round-trip test validates entity persistence end-to-end against a real PostgreSQL instance.
