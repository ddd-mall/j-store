The module is a Spring Boot auto-configuration library organized under `com.jstore.common.framework` with three sub-packages plus a `geo` utility package.

- `event/` provides a Spring-backed domain event bus: `SpringLocalDomainEventBus` delegates to Spring's `ApplicationEventPublisher`, while listener discovery is driven by `SpringDomainEventListenerRegistry` / `SpringDomainEventListenerRegistrationMachine` / `SpringDomainEventListenerTypeResolver`, which scan beans and resolve generic handler types via reflection; `SpringDomainEventMulticasterGuard` wraps async dispatch.
- `event/outbox/` implements the outbox pattern behind `OutboxAutoConfiguration`, which is gated by `@ConditionalOnProperty(prefix = "jstore.outbox", name = ["enabled"])`. It wires an `OutboxPublisher` that persists entries via `OutboxEntryRepositoryImpl` (JPA entity `OutboxEntryPO` + repository) and routes them through pluggable `OutboxDeliveryChannel` implementations (`LocalDomainEventDeliveryChannel` for in-process events, `BrokerIntegrationMessageDeliveryChannel` when a `BrokerIntegrationMessageTransport` bean is present). A scheduled `OutboxScheduler` drives retry/cleanup via `OutboxCleaner`, dead-lettering via `OutboxDeadLetterService`, and observability via `OutboxMonitor` (Micrometer-backed or `NoopOutboxMonitor`). Transactional relay is provided by `OutboxRelayTransactionOperations`.
- `messaging/` mirrors the outbox design for integration messages: `SpringLocalIntegrationMessageBus` resolves handlers from injected `List<IntegrationMessageHandler<*>>` using `ResolvableType` generic resolution, tracks consumption via `MessageConsumptionRepositoryImpl`, and `OutboxIntegrationMessagePublisher` bridges outbox entries to broker transports. `BrokerTransportModeGuard` selects between local and broker delivery based on `MessagingProperties.mode`.
- `geo/` exposes `GeoAddressServiceProxy` delegating to `CountryAddressProvider` implementations (e.g., `ChinaAddressProvider`) backed by `data/district.xlsx` read via FastExcel.

Dependency direction: this module depends on `j-store-common-core` (core abstractions), Spring Boot/JPA, Micrometer, Jackson, and FastExcel; it exposes `api` dependencies on Spring Data JPA so consumers can define their own entities, but all wiring is centralized in `OutboxAutoConfiguration` bean definitions.
