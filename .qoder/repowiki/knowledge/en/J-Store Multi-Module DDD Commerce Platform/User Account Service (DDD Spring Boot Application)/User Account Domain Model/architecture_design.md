Pure Kotlin JVM module expressing the UserAccount bounded context as a DDD aggregate. `UserAccount` is an interface extending the shared `AggregateRoot<UserId>` and `RecordsDomainEvents`, with `UserAccountImpl` providing state transitions (`changeNickname`, `changePassword`, `enable`, `disable`) that raise domain events via `EventRecordingAggregateRoot`. Value objects (`Nickname`, `Password`, `UserId`, `AuthTokenPair`) encapsulate invariants in their constructors. Creation logic is isolated in `UserAccountFactory`/`UserAccountFactoryImpl`, which validates password strength, hashes via injected `PasswordHasher`, generates IDs via `SnowFlakSequence`, and records the `UserAccountRegisteredEvent`. External concerns (phone verification, login attempt guarding, token persistence) are exposed as ports (`PhoneVerificationGateway`, `PhoneVerificationCodeSender`, `LoginAttemptGuard`, `TokenProvider`, `TokenStore`, `AccountSecurityPorts`) so the domain stays infrastructure-agnostic. Commands (`UserRegisterCMD`) and events live in sub-packages under `command/` and `event/`. The module depends only on `j-store-common-core` for shared framework types (`BusinessError`, `Result`, `DomainEvent`, `PhoneNumber`). Tests use Kotest property-based testing to assert value-object and factory invariants.
