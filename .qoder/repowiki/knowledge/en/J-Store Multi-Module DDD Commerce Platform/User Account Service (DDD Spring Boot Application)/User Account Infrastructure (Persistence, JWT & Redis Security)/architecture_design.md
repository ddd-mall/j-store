The module is a Spring Boot library that depends on `j-store-user-domain` via an `api` dependency, implementing the domain's repository and security interfaces with concrete infrastructure backends. It is organized into two packages mirroring domain concerns:
- `domain.useraccount.persistence/` holds the JPA entity `UserAccountPO` mapped to table `user_accounts` and the `UserAccountPOJpaRepository` Spring Data interface; `UserAccountRepositoryImpl` adapts domain `UserAccount` entities to POs through a private `Converter` object and enforces transactional boundaries via `@Transactional(propagation = MANDATORY)`.
- `security/` provides Redis-backed implementations of `LoginAttemptGuard` (`RedisLoginAttemptGuard`) and `PhoneVerificationGateway` (`RedisPhoneVerificationGateway`), both using `StringRedisTemplate` and Lua scripts (`DefaultRedisScript`) for atomic operations such as failure counting with TTL and challenge creation/consumption.
- Token handling lives in `JwtTokenProvider` (HS256 signed access/refresh tokens) and `RedisTokenStore` (session/refresh token storage), plus `BCryptPasswordHasher` wrapping Spring Security Crypto.
Dependency direction is one-way: this module consumes domain abstractions from `:j-store-user-domain` and `com.jstore.common.properties`, but exposes no domain types outward beyond what is needed by Spring DI.
