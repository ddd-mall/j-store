This module is the Spring Boot bootstrapping layer of the user service. It depends on `j-store-user-domain`, `j-store-user-application`, `j-store-user-infrastructure`, and shared `common`/`authentication-spring-sdk` modules, and exposes two REST controllers: `UserAccountController` under `/api/users` (public, protected by `@RequireLogin` with per-endpoint `@SkipLogin` overrides) and `InternalUserProfileController` under `/internal/api/users` (gated behind `ConditionalOnProperty(jstore.user-query.server.enabled=true)` and authenticated via a configured bearer token). Wiring is centralized in `UserBootConfiguration`, which constructs `UserAccountService`, `TokenProvider`, `TokenStore`, `PhoneVerificationGateway`, `LoginAttemptGuard`, and other beans from injected infrastructure components (e.g. `StringRedisTemplate`, `SnowFlakSequence`). A `TransactionalUserAccountUseCase` decorator wraps `UserAccountUseCase` to run write operations inside a `PlatformTransactionManager` transaction and perform Redis token side-effects only after successful commit; read-only queries use a separate read-only `TransactionTemplate`. `UserProfileQueryConfiguration` conditionally registers a local `UserProfileQueryService` when `jstore.user-query.mode=local` (default), while `DevelopmentPhoneVerificationSender` provides a no-op SMS sender for `local`/`dev` profiles.
