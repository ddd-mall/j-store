Kotlin JVM (toolchain 25) with Gradle Kotlin DSL. Testing uses Kotest (runner, assertions, property-based testing) and Mockito/Mockito-Kotlin. Domain events published via `DomainEventPublisher`; integration messaging via `IntegrationMessageHandler` from `j-store-common-framework`. Result type is a custom `Result<T, BusinessError>` monad used consistently across all use case methods.
