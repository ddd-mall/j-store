Pure Kotlin/JVM domain layer built on a shared `j-store-common-core` framework. Two bounded contexts are modeled as separate packages under `domain/`: `commodity` (SPU, Sku, GoodsStyle, Attribute, status machine, draft copy-on-write via `SpuFactory`, snapshot persistence through `SpuSnapshotRepository`, and domain events) and `inventory` (TCC reserve/deduct/release flow with `InventoryLock`, `ReservationRecord`, and `StorageErrors`). Each aggregate exposes an interface (`Spu`, `Inventory`) extending `AggregateRoot<T>` from `common.framework`, with a corresponding `*Impl` class that records domain events via `EventRecordingAggregateRoot`. Persistence is abstracted through repository interfaces (`SpuRepository`, `InventoryRepository`, `GoodsStyleRepository`, `ReservationRecordRepository`) extending a common `AggregateRepository<I, A>`. Cross-cutting infrastructure is kept out of the domain via the `acl/OssService` interface for image URL generation. Tests use Kotest FunSpec plus Kotest property-based testing to assert invariants over generated aggregates.
