The module is a Kotlin JVM Gradle project organized into two top-level packages. The `domain` package contains three aggregate roots — `LedgerAccount`, `JournalEntry` (with `JournalLine`), `AccountingPeriod`, and `SettlementStatement` (with `SettlementLine`) — each defined as an interface extending `AggregateRoot<T>` and `RecordsDomainEvents` from `com.jstore.common.framework`, with concrete implementations in sibling `*Impl.kt` files and repositories declared as interfaces (`LedgerAccountRepository`, `JournalEntryRepository`, `AccountingPeriodRepository`, `SettlementStatementRepository`). Each aggregate encapsulates its own error types under a local `*Errors.kt`. The `acl` package defines thin application-facing interfaces (`AccountingOrderService`, `AccountingPaymentService`, `AccountingShopService`) that return `Result<T, BusinessError>` and expose read models like `OrderAccountingInfo`, `PaymentAccountingInfo`, `ShopAccountingInfo`. Dependency direction is one-way: `acl` depends on `domain` (e.g., `SourceDocument`), while `domain` has no dependency on `acl`. Domain events are emitted per-aggregate via the shared `RecordsDomainEvents` contract, with event classes grouped under `journal/event` and `settlement/event` subpackages.
