The module implements the application layer of the Fulfillment service in Kotlin/JVM. It defines a single `FulfillmentUseCase` interface (create, read, prepare, dispatch, deliver) with `FulfillmentApplicationService` as its concrete implementation, which coordinates the `FulfillmentOrderRepository`, a `SnowFlakSequence` for ID generation, and a `DomainEventPublisher` to publish pending events after mutations. A separate `CreateFulfillmentForOrderCommandHandler` adapts inbound `CreateFulfillmentForOrderCommand` messages from `j-store-integration-contracts` into `FulfillmentRequest` DTOs and delegates to the use case via the `IntegrationMessageHandler` contract. The layer depends only on the domain project (`:j-store-fulfillment-domain`) and shared infrastructure (`:j-store-common-core`), keeping persistence and messaging concerns out of the domain. Build is a minimal Gradle Kotlin DSL setup targeting JVM 25 with Kotest for tests.
