This module is the Spring Boot bootstrapping layer for the fulfillment service. It declares three Kotlin packages under `com.jstore.fulfillment`: `config` holds Spring `@Configuration` beans that assemble `FulfillmentApplicationService`, a `@Primary` `TransactionalFulfillmentUseCase` decorator wrapping all use-case methods in read/write `TransactionTemplate`s, and a `CreateFulfillmentForOrderCommandHandler`. The `controller` package exposes a single `@RestController` (`FulfillmentController`) mapped under `/api/fulfillments` that delegates to the `FulfillmentUseCase` interface and enforces per-request merchant authorization via `MerchantAuthorizationService`. Dependency direction is strictly inward: this module depends on `j-store-fulfillment-domain`, `j-store-fulfillment-application`, `j-store-fulfillment-infrastructure`, plus shared modules (`j-store-common-core`, `j-store-common-spring`, `j-store-integration-contracts`, `j-store-shop`, `j-store-authentication-spring-sdk`). The `bin/` mirror duplicates the compiled classes for IDE/run configurations, while tests live alongside sources under `src/test/kotlin`.
