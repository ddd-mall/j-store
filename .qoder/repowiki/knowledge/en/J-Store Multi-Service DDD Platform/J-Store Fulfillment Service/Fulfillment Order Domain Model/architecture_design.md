Pure Kotlin/Java module built with Gradle (`build.gradle.kts`) targeting JVM 25. The aggregate is modeled as an interface (`FulfillmentOrder`) implemented by `FulfillmentOrderImpl`, following a classic DDD pattern where the interface exposes behavior (`prepare`, `dispatch`, `deliver`) and immutable state, while the implementation holds mutable internal fields (`_status`, `_carrierCode`, `_trackingNumber`). State transitions are enforced inside each method and return `Result<Boolean, BusinessError>` from `com.jstore.common.utils`. Domain events live in a separate `event` subpackage as a sealed hierarchy (`FulfillmentEvent`) with concrete data classes annotated via `@DomainEventType`, raised through `raise()` on `EventRecordingAggregateRoot`. Persistence is abstracted by `FulfillmentOrderRepository : AggregateRepository<FulfillmentOrderId, FulfillmentOrder>` plus a `findByOrderId` query. All shared infrastructure types (`BusinessError`, `AggregateRoot`, `RecordsDomainEvents`, `Id`, `Result`) come from the sibling `:j-store-common-core` project, keeping this module dependency-free beyond that core.
