Single-package Kotlin/JVM module implementing the application layer of the payment bounded context. `PaymentUseCase` defines the use-case interface; `PaymentApplicationService` is the concrete implementation that coordinates `PaymentOrderRepository`, `SnowFlakSequence` (for ID generation), and `DomainEventPublisher`. Domain entities (`PaymentOrder`, `PaymentRefund`) live in `:j-store-payment-domain` and are mutated through repository methods; changes are persisted via `persistAndPublish` which saves the entity and publishes pending domain events. `PaymentIntegrationMessageHandlers` implements `IntegrationMessageHandler` for two inbound integration contracts (`CreatePaymentForOrderCommand`, `RequestPaymentRefundCommand` from `:j-store-integration-contracts`), translating them into application requests. Dependency direction is strictly inward: this module depends on domain and common infrastructure but exposes no persistence or messaging internals.
