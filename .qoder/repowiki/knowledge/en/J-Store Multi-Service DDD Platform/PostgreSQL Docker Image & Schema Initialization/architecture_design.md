Single-purpose Docker image built from `postgres:16-alpine` that copies only the first init script (`01-init.sql`) into `/docker-entrypoint-initdb.d/`, letting PostgreSQL's native entrypoint execute all `init/*.sql` files in numeric order. The init scripts are strictly versioned and additive: `01-init.sql` creates the `develop` schema and grants permissions; subsequent scripts (`02-` through `09-`) add columns or create new tables such as `outbox_entry` and `domain_event_consumption`. There is no ORM or migration tooling — schema evolution is purely file-based and executed once at container startup by PostgreSQL's built-in initializer.
