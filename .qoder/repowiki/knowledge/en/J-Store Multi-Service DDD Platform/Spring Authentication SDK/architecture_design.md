The module is a Spring Boot starter built around a `HandlerInterceptor` (`AuthenticationInterceptor`) that runs on every MVC request. It composes three layers: (1) annotation layer in `annotation/` — `@RequireLogin`, `@SkipLogin`, and `@CurrentUserId`; (2) runtime context layer in `context/` — a `ThreadLocal<UserId>` exposed through `AuthenticatedUserContext` plus an `AuthenticationException`; (3) Spring integration layer in `spring/` — `AuthenticationAutoConfiguration` registers the interceptor, the `CurrentUserIdArgumentResolver`, and a `WebMvcConfigurer`. Configuration is extensible via the `AuthenticationConfigurer` interface so consumers can declare path patterns for authentication and exclusion. The auto-configuration is declared through `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` and is gated by `@ConditionalOnBean(TokenProvider, TokenStore)` and `@ConditionalOnWebApplication(SERVLET)`. Dependency direction is one-way: `spring/` depends on `config/`, `context/`, `annotation/`, and `error/`; `context/` only depends on `user.domain.UserId` from `j-store-user-domain`; no component imports another sibling package except through these boundaries.
