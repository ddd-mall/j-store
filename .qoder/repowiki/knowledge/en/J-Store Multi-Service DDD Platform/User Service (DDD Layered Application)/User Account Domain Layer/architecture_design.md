Pure Kotlin/Java module implementing a DDD aggregate-root pattern. The core is the `UserAccount` interface (`UserAccount.kt`) extended from `AggregateRoot<UserId>` and `RecordsDomainEvents`, with `UserAccountImpl` as its concrete implementation that records domain events via `EventRecordingAggregateRoot`. Creation is delegated to `UserAccountFactory` / `UserAccountFactoryImpl`, which validates inputs, hashes passwords through the injected `PasswordHasher`, generates IDs via `SnowFlakSequence`, and raises `UserAccountRegisteredEvent`. Persistence is abstracted by the `UserAccountRepository` interface extending `AggregateRepository<UserId, UserAccount>`, kept in the domain so implementations live in the infrastructure layer. Value objects (`Nickname`, `Password`, `UserId`, `AuthTokenPair`) enforce invariants in their constructors. Domain events live under `event/` and are annotated with `@DomainEventType`. Commands (`command/UserRegisterCMD`) carry inbound data into the factory. Tests use Kotest property-based testing (`checkAll`) to verify invariants across generated inputs.
