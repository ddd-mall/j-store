This module is an infrastructure layer that depends on `:j-store-user-domain` (declared as `api(project(...))`) and provides concrete implementations of domain abstractions. It follows a clean-architecture adapter pattern: `UserAccountRepositoryImpl` bridges the domain `UserAccountRepository` to a Spring Data JPA repository (`UserAccountPOJpaRepository`) through an internal `Converter` object that maps between the domain entity and the JPA `@Entity` PO (`UserAccountPO`). Token persistence is split across two adapters — `JwtTokenProvider` (stateless HS256 signing via jjwt) and `RedisTokenStore` (stateful refresh-token storage and access-token blacklist via `StringRedisTemplate`). Password hashing is delegated to `BCryptPasswordHasher`, which wraps Spring Security's `BCryptPasswordEncoder`. All adapters are registered as Spring beans via `@Repository` or constructor injection, keeping the domain free of infrastructure concerns.
