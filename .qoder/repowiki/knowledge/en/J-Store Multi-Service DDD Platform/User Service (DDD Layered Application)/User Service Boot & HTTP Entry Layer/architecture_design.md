This module is the deployment/entry point of the user service. It depends on three internal modules — `:j-store-user-domain`, `:j-store-user-application`, `:j-store-user-infrastructure` — plus shared `:j-store-common-core`, `:j-store-common-spring`, and `:j-store-authentication-spring-sdk`. Wiring is centralized in `UserBootConfiguration`, which declares `@Bean`s for factories (`UserAccountFactory`, `BCryptPasswordHasher`), infrastructure adapters (`JwtTokenProvider`, `RedisTokenStore`), the application service (`UserAccountService`), and a `@Primary` `TransactionalUserAccountUseCase` decorator that wraps write operations in Spring `TransactionTemplate` while deferring Redis token mutations to after commit. The HTTP surface is a single `UserAccountController` exposing `/api/users/*` endpoints; all responses go through a `Result<T,BusinessError>.toResponse` helper that folds success/failure into `ResponseEntity`. Authentication is implemented as a `OncePerRequestFilter` (`JwtAuthenticationFilter`) registered via `FilterRegistrationBean` with URL pattern `/api/*` and order 1, skipping whitelisted register/login/refresh-token paths and injecting `userId` into the request attribute on success.
