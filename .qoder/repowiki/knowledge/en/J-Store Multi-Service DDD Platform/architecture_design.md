The root is a Gradle composite project (`settings.gradle.kts`) that declares every module by `include(...)`, establishing a strict dependency hierarchy: `j-store-common-core` and `j-store-common-spring` are foundational libraries consumed by all services; each bounded context (order, goods, user, shop, accounting, payment, fulfillment) is split into domain/application/infrastructure/boot submodules following the same four-layer DDD pattern; `j-store-order-boot` acts as the primary orchestration application wiring all contexts together. Cross-cutting concerns (authentication, outbox messaging, domain events) are centralized in `j-store-authentication-spring-sdk`, `j-store-common-core`, and `j-store-common-spring`. Database schema and migrations live in `docker-compose.postgres.yml` plus SQL migration scripts, while `tests/` enforces module boundary contracts via Python unittests. The root `build.gradle.kts` centralizes Java 25 toolchain, Spotless formatting (ktfmt/google-java-format), and CycloneDX BOM generation for all subprojects.
