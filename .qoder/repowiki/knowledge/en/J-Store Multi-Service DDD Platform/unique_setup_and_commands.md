Build the entire platform with `./gradlew build`; format code with `./gradlew spotlessApply`; generate SBOM via `./gradlew cyclonedxDirectBom`; run individual services through their respective `*-boot` modules (e.g., `./gradlew :j-store-order-boot:bootRun`). Database bootstrap uses `docker-compose -f docker-compose.postgres.yml up` which applies numbered SQL migrations to create the develop schema.
