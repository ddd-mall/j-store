This repository is a backend-only Spring Boot multi-module Kotlin/Java project implementing an e-commerce platform using DDD. There is no frontend code, CSS, HTML templates, or UI styling system present anywhere in the codebase. All modules are server-side: domain modules (order, goods, user, accounting), infrastructure layers, and Spring Boot application entry points. No .css, .scss, .html, .jsp, or frontend framework files exist. The controllers exposed are REST APIs without any view rendering or client-side assets.
