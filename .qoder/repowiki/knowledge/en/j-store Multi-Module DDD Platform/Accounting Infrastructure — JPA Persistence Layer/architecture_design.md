The module implements the infrastructure layer of a DDD accounting system. It is organized by domain aggregate (`account`, `journal`, `settlement`), each containing three sub-packages: a `persistence/` folder with JPA `@Entity` PO classes (e.g. `JournalEntryPO`, `JournalLinePO`) and Spring Data `*JpaRepository` interfaces, plus a `*RepositoryImpl` class that implements the domain's repository interface from `j-store-accounting`. Each `RepositoryImpl` is annotated with `@Repository` and holds a single `*JpaRepository` dependency; it performs bidirectional conversion via an inner `object Converter` with `toPO` and `toDomain` methods, keeping domain logic free of persistence concerns. The build declares `api(project(":j-store-accounting"))`, making the domain interfaces available to consumers while the JPA dependencies stay internal. Tests use an in-memory H2 database configured via `AccountingJpaTestConfig` with `@EntityScan` and `@EnableJpaRepositories` scoped to `com.jstore.accounting`.
