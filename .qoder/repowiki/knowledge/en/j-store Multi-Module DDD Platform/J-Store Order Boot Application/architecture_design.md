This module is the Spring Boot executable assembly for the j-store platform. `JStoreOrderBootApplication.kt` is the single `@SpringBootApplication` entry enabling JPA auditing, scheduling, and configuration properties scanning. Each bounded context (order, goods, user, accounting) contributes its own `*BootConfiguration.kt` under `com/jstore/<context>/config/`, which registers domain factories, services, event handlers, and cross-context ACL adapters as `@Bean`s — keeping wiring explicit and testable. Controllers live under each context's `controller/` package (`OrderController`, `AfterSaleController`, `UserAccountController`) and are exposed through `/api/*`. Authentication is handled by a `JwtAuthenticationFilter` registered via `FilterRegistrationBean` in `UserBootConfiguration`. Persistence uses Spring Data JPA with PostgreSQL, schema evolution via Flyway migrations under `resources/db/migration/`, and an initial seed under `resources/db/init/`. Redis is used for token storage and the timer-job subsystem; Lua scripts under `script/` implement atomic job pick/rollback operations. The `order/expired` package implements a custom distributed timer-job coordinator with `TimerJobCoordinator`, `Worker`, `SlotAssigner`, `RetryTimes`, and dead-letter queues, wired through `RedisConfig`. Event translation between order and stock domains is provided by `OrderToStockEventTranslator` and `StockToOrderEventTranslator`. Tests use embedded Postgres (`io.zonky.test:embedded-postgres`) and JUnit 5.
