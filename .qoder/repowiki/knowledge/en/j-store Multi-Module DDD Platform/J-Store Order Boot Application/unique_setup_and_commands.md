Run with `./gradlew bootRun` (defaults to the `local` profile) after providing the required `JSTORE_*` environment variables described in `.env.example`. Database schema is bootstrapped via Flyway baseline version `20260507` against PostgreSQL; local development defaults to `localhost:30432/j_store` with schema `develop`. Tests require no external database thanks to `io.zonky.test:embedded-postgres:2.1.0`. The Docker image uses an Amazon Corretto 25 runtime matching the Gradle Java 25 toolchain.
