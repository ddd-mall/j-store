The module is a Spring Boot application that implements interfaces defined in `:j-store-order` (the domain layer) via three sub-packages:
- `domain.order.persistence` and `domain.aftersale.persistence`: JPA entity models (`OrderPO`, `RecipientInfoPO`, `AfterSalePO`, etc.) with `@Entity`/`@Table` annotations and Spring Data JPA repository interfaces (`OrderPOJpaRepository`, `AfterSalePOJpaRepository`). Complex JSON columns use custom `AttributeConverter` implementations (`I18nGeoAddressConverter`, `RecipientInfoPOConverter`) to serialize/deserialize Kotlin data classes.
- `domain.order` and `domain.aftersale`: Repository implementations (`OrderRepositoryImpl`, `AfterSaleRepositoryImpl`) annotated with `@Repository` that translate between domain entities and POs via internal `Converter` objects. They encapsulate transaction management using `TransactionTemplate` and handle concurrency via optimistic locking (`@Version`) and explicit row-level locks (`findByIdForUpdate`).
- `acl`: Anti-Corruption Layer adapters wrapping external APIs — `GoodsServiceImpl` adapts `GoodsSnapshotQueryService` from `:j-store-goods-api`, and `ConfiguredAfterSaleMerchantResolver` resolves merchant IDs for after-sale flows.
- `service`: Event-driven projection service `OrderRefundProjectionServiceImpl` consumes `AfterSaleApprovedEvent` and updates order state via the order repository converter.

Dependency direction is strictly inward: this module depends on `:j-store-order` (API/domain) and `:j-store-goods-api`, but nothing inside the domain layer depends back on infrastructure. Tests under `src/test/kotlin` mirror the source structure and use Kotest property-based tests for PO round-trip and backward compatibility.
