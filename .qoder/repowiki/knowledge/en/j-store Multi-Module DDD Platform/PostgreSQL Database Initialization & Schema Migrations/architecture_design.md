Single-purpose Docker image built from `postgres:16-alpine` that copies SQL migrations into `/docker-entrypoint-initdb.d/`, which PostgreSQL's official entrypoint executes in numeric order on first container start. The `init/` directory holds versioned migration scripts (01–09) that are applied exactly once per database lifecycle; each script is self-contained and uses `IF NOT EXISTS` guards so re-runs are safe. Migration 01 creates the `develop` schema and configures the default role/search path, while subsequent scripts add domain tables (outbox, goods, orders) and indexes. There is no ORM or migration framework — raw SQL is the sole source of truth for schema evolution.
