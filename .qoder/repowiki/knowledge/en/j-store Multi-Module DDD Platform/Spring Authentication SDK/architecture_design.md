The module is a self-contained Spring Boot starter built around three layers. The `spring` package provides the Spring integration: `AuthenticationAutoConfiguration` (registered via `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`) conditionally registers an `AuthenticationInterceptor` (implements `HandlerInterceptor` to parse Authorization headers, validate tokens through `TokenProvider`/`TokenStore`, and set `AuthenticatedUserContext`), a `CurrentUserIdArgumentResolver` (injects `UserId` into handler methods annotated with `@CurrentUserId`), and a `WebMvcConfigurer` bean that registers both. The `config` package exposes `AuthenticationConfigurer` as an extension point so consumers can declare path patterns for required/excluded authentication. The `context` package holds the thread-local `AuthenticatedUserContext` (with `set`/`getCurrentUserId`/`getCurrentUserIdOrNull`/`clear`) and a lightweight `AuthenticationException`. The `annotation` package defines `@RequireLogin`, `@SkipLogin`, and `@CurrentUserId`. The `error` package centralizes `BusinessError` constants (`TOKEN_MISSING`, `TOKEN_INVALID`, `TOKEN_BLACKLISTED`, `INTERNAL_ERROR`). Dependency direction is one-way: `spring` → `config`/`context`/`error`/`annotation`; `spring` depends on `j-store-user` for `TokenProvider`/`TokenStore`/`UserId` but no other package depends back on `spring`, keeping the core reusable outside web contexts.
