The module is organized into two top-level packages under `com.jstore.common`:
- `framework.event`: Implements a Spring-based domain event bus (`SpringDomainEventBus`) that delegates to Spring's `ApplicationEventPublisher`, with listeners wrapped via `DomainListenerSpringWrapper` and registered through `SpringDomainEventListenerRegistry`. A consumption tracking mechanism persists delivery state via `DomainEventConsumptionPO`.
- `framework.event.outbox`: A full outbox pattern implementation gated by `@ConditionalOnProperty(prefix = "jstore.outbox", name = ["enabled"])`. `OutboxAutoConfiguration` wires all beans: `OutboxEventPublisher` (persists events), `OutboxPublisher` (polls and dispatches via `DomainEventBus`), `OutboxCleaner` (retention), `OutboxScheduler` (cron-driven orchestration), `OutboxDeadLetterService`, `OutboxMonitor` (Micrometer-backed or noop), and transaction coordination via `OutboxRelayTransactionOperations`. Persistence uses JPA (`OutboxEntryPOJpaRepository`) with `OutboxEntryRepositoryImpl` as the repository facade. Event serialization is pluggable via `EventSerializer` with `JacksonEventSerializer` as default, plus upcasting support.
- `geo`: A `GeoAddressServiceProxy` that resolves `CountryAddressProvider` implementations by country code, with a built-in `ChinaAddressProvider` using `district.xlsx` data.

Dependency direction: this module depends on `j-store-common-core` for shared interfaces (`DomainEventBus`, `DomainEventPublisher`, `GeoAddressService`, etc.) and exposes them as `api` dependencies so consumers can depend only on this Spring module.
