This module is a Spring Boot infrastructure layer that implements interfaces defined in the `:j-store-user` domain module (`api(project(":j-store-user"))`). It follows a clean-architecture split: domain interfaces (e.g. `UserAccountRepository`, `TokenProvider`, `PasswordHasher`, `TokenStore`) are consumed here while concrete implementations live under `com.jstore.user.domain.useraccount`. The JPA layer defines an `@Entity` PO (`UserAccountPO`) and a Spring Data repository interface (`UserAccountPOJpaRepository`), with `UserAccountRepositoryImpl` bridging domain entities to persistence objects via a private `Converter` object. Token handling is split across `JwtTokenProvider` (HS256-signed access/refresh tokens) and `RedisTokenStore` (refresh token cache + access token blacklist). All components are annotated as Spring beans (`@Repository`) and wired through constructor injection.
