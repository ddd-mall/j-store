The root is a Gradle settings-driven multi-module build that declares all subprojects in settings.gradle.kts under group com.jstore. Each bounded context follows a consistent split: a *_domain module defines aggregates, factories, application services, and ACL adapters; a *_infrastructure module provides JPA repositories, Spring Data adapters, and persistence mappings. Cross-cutting concerns are centralized in j-store-common-core (domain primitives, event bus, Result type, i18n geo-address), j-store-common-spring (Spring integration, outbox pattern, geo proxy), and j-store-authentication-spring-sdk (JWT token validation, ThreadLocal UserId, access-control annotations). The j-store-boot module is the single Spring Boot entry point that wires together all domain/infrastructure modules, while j-store-admin-boot serves as an admin-facing boot application. PostgreSQL schema migrations live in the infrastructure module and are applied via Flyway, with Docker Compose providing local dev Postgres and Redis aligned to application-local.properties.
