## 收货地址

订单中的收货信息用于发货时对接仓储系统,因此需要满足以下要求:

1. 有收货人姓名与联系电话
2. 有详细地址信息(买家输入的地址信息,不需要进行地址解析)
3. 行政区划编码.
4. 提交订单时通过地址信息服务校验行政区划编码是否有效.(是否能用给定区划编码查询到对应的地址信息)

### 能用来发货/收获

需要有以下信息:

1. [x] 邮政编码/行政区划编码
2. [x] 详细地址信息
3. [x] 收货人姓名
4. [x] 收货人联系方式
5. [x] 使用一个jsonb字段将以上信息组成的对象存储在订单中
